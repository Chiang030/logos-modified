# LOGOS 字标研究与结构方案

2026-10-08。目标是在真实终端字符约束下，设计能与纸飞机、轨道和星星建立联系的原创字标。

## 已查看的参考案例

- [Danne & Blackburn / NASA，MoMA 藏品页面](https://www.moma.org/collection/works/467589)：观察圆弧转折、统一笔画以及字母之间的连续关系。借鉴的是组织字母的方法。
- [Pentagram / Vertical](https://www.pentagram.com/work/vertical)：工作室说明品牌从飞行器曲线、几何与蜂鸟形象中提取视觉语言，且把实际飞行运动用于动效原则。LOGOS 应从自己的纸飞机与轨道符号发展字标。
- [Paul Rand / IBM，IBM 官方历史页面](https://www.ibm.com/history/logo)：观察重复线条、负空间和统一节奏如何形成识别度。流场方案将这一思路转为成对的连续轮廓线。

## 三种独立方向

1. **轨道连笔（默认）**：L 与首个 O 共享底部连笔；两个 O 使用相同轨道轮廓和局部切口；G 的金色导向笔画成为视觉焦点。S 使用连续曲线呼应轨道。
2. **机翼负形**：厚实直立的笔画，O/G 内部采用后掠翼形的留白，配合一致的斜向切缝。更强调航空结构感。
3. **流场线条**：双线轮廓与连续负空间，让字母像被流线包围。更轻，适合作为偏仿真、工程图纸的方向。

三版共用 48 列 × 8 行画布，不通过斜体或拉伸来制造区别。终端显示仍由 Unicode 点阵字符组成，也提供纯 ASCII 降级。保留纸飞机图标、顺时针变速星轨与 AIRCRAFT DESIGN & SIMULATION AGENT 副标题。

预览页可切换三版。CLI 默认使用轨道连笔，环境变量 `LOGOS_WORDMARK=wing` 或 `LOGOS_WORDMARK=flow` 可切换其它方案。
