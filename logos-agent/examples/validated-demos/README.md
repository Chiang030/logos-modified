## 不运行软件的离线复核

在本目录执行（Python 3.10+，仅标准库，不联网、不安装依赖、不写入证据）：

```bash
python verify_demo_evidence.py
```

校验包含结构成功/错误截面负例、CFD 成功双网格/未收敛负例、最终残差以及 KiCad ERC、网表、LED 极性和 PCB 一致性。**脚本返回成功只表示保留材料满足这些检查，不表示刚刚完成了一次新求解。**

## 文件组织与公开材料

每个领域各自保留脚本、`results/` 成功产物、`attempts/` 失败尝试和 README。真实重跑命令、参数、依赖、输出目录保护和验收阈值详见各领域 README。重跑需要用户已安装的软件及合法可用的许可，脚本不安装依赖、不设置许可证服务器、不修改全局配置，也不操作他人的进程。

- 数值 CSV/JSON、ASCII 网格、KiCad 项目与制造输出保留真实结果；未为了通过验收修改数值。
- 公开求解文本输出使用 `.txt` 后缀；仅替换主机、用户名、网络端点、安装路径、临时目录与许可元数据。文件开头标明去标识化，不冒充原字节副本。
- KiCad XML 网表只去除了源文档绝对路径，电气连接与脚号未改动。
- 原始未脱敏材料完整保留于维护者的私有本地归档。许可证日志、内部服务器诊断、完整第三方符号库不进入本目录。
- ANSYS 原生二进制结果（RST/DB、Fluent HDF5 case/data）可能携带环境元数据，**未放入公开仓库**；Fluent HDF5 已发现历史路径。使用脚本在自己的环境重跑可生成对应原生结果。不能把本仓库视为这些二进制文件的公开镜像。

## LOGOS 网页演示

网页“标准算例”入口可复制本目录中的公开脚本与证据到个人示例项目；导入不自动调用模型或启动求解器。先读项目 README，再要求智能体解释参数、复算指标；需要重跑时明确授权新输出目录并检查依赖、许可和结果。不要把一次回复结束、程序退出码为零或软件启动成功当作工程验收。

KiCad 原理图缓存的 `Device:R`、`Device:LED`、`Connector_Generic:Conn_01x02` 来自已安装的 KiCad 标准符号库；本项目不声称这些符号为原创，亦不重新许可第三方内容。重跑使用用户已有的库，不捆绑完整库副本。
