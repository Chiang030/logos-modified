## 逐章验收

| 章节 | 状态 | 实现与证据 |
| --- | --- | --- |
| 1. 实现前提 | 完成 | 首版为 React Web + FastAPI；单 Agent 推理由 Deep Agents SDK/LangGraph 提供，未以 DeepAgent Code 产品为基座。 |
| 2. 智能体体系 | 完成 | `chief_engineer`、`modeling_agent`、`validation_agent` 是三个独立注册身份；总师通过 Control Plane 派发，用户可直接进入任一 Agent Session。 |
| 3. 核心对象与层级 | 完成 | SQLAlchemy 模型覆盖 Workspace、Agent、AgentSession、Message、Run、Task、Artifact、ChangeSet、Revision、Event 和 WorkspaceMember；每个 Session 有独立 `thread_id`。 |
| 4. 独立入口与通信 | 完成 | `langgraph.json` 注册三个 Graph；消息保留 sender/recipient/session/task/reply/sequence/status；浏览器用例验证总师消息在目标 Session 可见且用户可直接回复。 |
| 5. Session 管理与派发 | 完成 | API 和 Web 均支持新建、继续明确 Session、Fork 明确 Session/Checkpoint；Fork 复制数据库消息、Session 文件，并在首次 LangGraph Run 重放继承上下文。 |
| 6. 工作区体系 | 完成 | `WorkspaceStorage` 路由 shared/private/session/run 四层逻辑空间；共享区禁止直接写入，Agent 私有区受 Agent Session 权限隔离。 |
| 7. 版本与发布 | 完成 | ChangeSet 检查角色、发布类型、基线版本和冲突，计算 SHA-256，创建不可变快照与 Artifact，发布事件并支持历史版本恢复。 |
| 8. 运行与并发 | 完成 | 每条输入创建 Run；同 Session 单 worker 串行，不同 Session 并行；系统和 Agent 双层并发额度；Inbox 排队、取消/中断、错误和重启恢复已实现。 |
| 9. Control Plane | 完成 | 模块化 Control Plane 管理成员权限、Session、消息、任务、Run、版本和事件；Agent 工具通过 HTTP 调用 Control Plane，不做隐藏同步 Agent 调用。 |
| 10. Web 前端 | 完成 | 三栏桌面布局和移动端三视图；左栏 Agent/Session，中栏真实发送者、消息、Run/工具状态和停止操作，右栏任务、Run、文件、Artifact、Revision，并支持会话/项目范围。 |
| 11. 数据与存储 | 完成 | PostgreSQL 生产配置验证通过；SQLite 用于隔离测试并启用 WAL；LangGraph Thread、版本化本地产物和持久化 SSE 事件均已接入。 |
| 12. 首版部署 | 完成 | 一个 Vite Web、一个 FastAPI Control Plane/Workspace Service/Worker、一个多 Graph LangGraph Server、一个 PostgreSQL 和一个 Artifact Storage，保持模块边界。 |
| 13. 实施顺序 | 完成 | 三 Graph、直接多轮、数据模型、多 Session、三种派发、Inbox、四层工作区、ChangeSet、事件和 Web、恢复/取消/权限全部实现。 |
| 14. 暂不扩张项 | 符合 | 未创建物理场常驻 Agent、未拆微服务、未开放递归调用、未展示思维链、未实现跨机器队列、未允许无版本共享覆盖。 |
| 15. 核心原则 | 完成 | 独立 Agent 入口、多 Session/Thread、用户与 Agent 共用消息入口、LangGraph 与 Control Plane 分责、私有工作与版本化共享协作均已落实。 |

- LangGraph Fork：运行输入包含源 `message:2` 前的历史消息及新任务。

## 运行边界

- 本地默认 deterministic runtime 用于无密钥完整协议验证；设置 `LOGOS_RUNTIME_MODE=langgraph` 后使用 Agent Server。
- HTTP 身份头必须由生产反向代理在认证后覆盖；应用层已执行 Workspace owner/editor/viewer 和 Agent Session 隔离。
- SQLite 是本地与测试模式；生产部署使用 PostgreSQL。
