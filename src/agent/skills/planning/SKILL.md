# Logos planning

Ask for missing boundary conditions, constraints, and observable acceptance
criteria before submitting a plan. Planning does not execute modeling or start a
separate workflow. The deterministic LangGraph assigns identifiers and routes an
adopted plan to the modeling Agent.

The current executor produces placeholder artifacts only. Never describe them as
real solver results, numerical validation, or engineering acceptance.
